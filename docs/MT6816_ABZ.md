# MT6816 ABZ 增量编码器接入

本工程不再通过 SPI1 读取 MT6816。PA6、PA7 分别复用为 TIM3_CH1、TIM3_CH2，TIM3 使用 Encoder Interface / TI12 模式，对 A、B 两相的四个边沿计数。

## 接线

| MT6816 信号 | STM32 信号 | 说明 |
| --- | --- | --- |
| A（5 脚） | PA6 / TIM3_CH1 | 正交 A 相，经 3.3 V 电平转换后接入 |
| B（6 脚） | PA7 / TIM3_CH2 | 正交 B 相，经 3.3 V 电平转换后接入 |
| VDD（4 脚） | 5 V | VDD-GND 就近放置 0.1 µF 去耦 |
| GND（8 脚） | GND | 必须共地 |
| HVPP（2 脚） | GND | 低电平选择 ABZ/UVW 模式 |
| Z（7 脚） | 未接 | 当前实现不使用索引脉冲 |

MT6816 可以使用 3.0–5.5 V 供电，但 PA6/PA7 在 STM32G474 上是 `TT_a` 引脚，不是 5 V 容忍引脚。若 MT6816 使用 5 V 供电，A/B 是接近 5 V 的推挽输出，必须经过双通道逻辑电平转换器，或每相使用 `2.2 kΩ` 上臂、`3.3 kΩ` 下臂分压到约 3.0 V。也可以让 MT6816 使用 3.3 V 供电。

HVPP 必须接地才能选择 ABZ 模式。芯片上电后的前 16 ms 没有 ABZ 输出；当前启动流程远长于 16 ms，不需要额外等待。CSN/PB2 不参与 ABZ 计数。

## 分辨率

`MT6816_AB_PULSES_PER_REV` 表示手册中的每圈 AB 脉冲数。默认值为 1024；TIM3 的四倍频计数因此是 4096 count/rev。若芯片后缀或 MTP 配置对应 1000、512 等其他脉冲数，必须修改该宏，否则机械角、速度和电角度都会按相同比例出错。

## 控制流程

1. TIM3 以 16 位自由运行计数器工作，输入数字滤波等级为 2。
2. 20 kHz 电流环每次直接读取 TIM3->CNT，通过有符号 16 位差值处理回绕，并累计多圈位置。
3. 每 20 个电流环样本发布一次编码器增量，1 kHz 速度环据此计算 rad/s。
4. 单个 50 us 周期内超过 256 count 的跳变视为干扰；连续 8 次异常后触发编码器故障。
5. 只有 A/B 时，上电计数零点与转子绝对位置无关。因此每次上电都执行开环电角度对齐，同时确定 A/B 方向和电角度偏置。若以后接入 Z 相或霍尔传感器，可再改为索引回零或绝对扇区初始化。

这种结构沿用了 TIGERs 固件的关键做法：硬件正交计数、电流周期同步取位置、按固定数量的电流周期累计速度。TIGERs 还用霍尔信号建立上电绝对扇区并校正漏计数；本硬件没有这条观测通道，所以不能省略启动对齐。
